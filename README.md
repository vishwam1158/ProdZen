# ProdZen

**A mindful digital-wellbeing companion for building healthier relationships with your phone.**

ProdZen helps people understand their screen habits, set intentional boundaries, and pause before getting pulled into distracting apps, short-form feeds, and websites.

## Live demo

Visit **[prodzen.logicappstudio.tech](https://prodzen.logicappstudio.tech/)** to explore the live ProdZen website.

## Product context

ProdZen is designed around a simple idea: digital wellbeing should support intentional choices instead of creating more pressure. The product experience centers on:

- Clear screen-time and app-usage insights
- Mindful limits, focus sessions, goals, and intentions
- Customizable pause and intervention experiences for distracting apps, websites, and short-form content
- Progress summaries and weekly reflections
- Privacy-conscious controls for the data and permissions the user enables
